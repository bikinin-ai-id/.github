# Bikinin.id

Agent untuk pekerjaan bisnis. Anda menjelaskan pekerjaannya, Bikinin menyusun alurnya, menguji tiap langkah, lalu menyambungkannya ke penyedia pesan yang dipakai tim.

</p>

## Cara kerjanya

| | Tahap | Yang terjadi |
|---|---|---|
| 1 | **Prompt** | Pekerjaan ditulis dengan bahasa biasa, seperti menjelaskan ke tim. |
| 2 | **Alur** | Langkahnya tersusun dari kalimat itu, tanpa blok yang diseret. |
| 3 | **Uji** | Alur dijalankan dengan contoh. Hasil tiap langkah tercatat dan bisa dibuka. |
| 4 | **Pesan** | Setelah lolos uji, agent disambungkan ke penyedia pesan. |
